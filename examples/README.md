# Framework Examples

This directory contains concrete examples of how to leverage the **everton-ai-agent-kit** for professional software engineering.

## 📂 Contents

| File | Description |
| :--- | :--- |
| [task-api-prompt.md](./task-api-prompt.md) | A master prompt example for building a complex REST API. |
| [java-spring-workflow.md](./java-spring-workflow.md) | Detailed walkthrough of the Agent collaboration lifecycle. |
| [generated-project-example.md](./generated-project-example.md) | A mockup of a project structure generated by the kit. |

## 💡 How to use these examples

1. **Learning**: Read the `java-spring-workflow.md` to understand how the Maestro dispatches work.
2. **Inspiration**: Copy patterns from `task-api-prompt.md` to structure your own requests.
3. **Benchmarking**: Compare your AI's output with `generated-project-example.md` to ensure it's following the rules.
